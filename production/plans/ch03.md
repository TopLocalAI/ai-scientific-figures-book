## 1. 章标题与学习目标

- 中文：**第三章　与 AI 一起推演构图和草图**
- English: **Chapter 3　Working Out Layout and Sketches with AI**

读完本章，读者能够：

1. 用"入口—路径—终点"三个问题描述一张图的阅读顺序，并用主次（大小、位置、对比）和分组（接近、对齐、围合）去控制它。
2. 判断哪些内容应当放进同一面板、哪些应拆成插图或独立面板，并写出判断理由。
3. 对同一份内容画出至少三种结构不同的草图（线性、中心辐射、分支对比），再用 SciDraw AI 的草图模式把每张草图变成候选图。
4. 用一张写明标准的比较表在候选图之间作出选择，而不是凭"哪张更好看"。
5. 每次修改只提出一个可核对的目标，并记录未要求却发生的变化（意外变化日志）。

## 3. 主案例：CRISPR–Cas9 基因组编辑总览图

### 3.1 研究情境

一位做细胞模型的分子生物学博士生，需要在开题报告和一篇综述的引言中放一张 **Figure 1 总览图**，交代 CRISPR–Cas9（以化脓链球菌 SpCas9 为例）在哺乳动物细胞中如何产生定点双链断裂，以及细胞的两类主要修复途径如何决定编辑结果。图中不报告任何新数据，只总结教科书与综述层面已确立的知识；她后续的结果图会在此基础上说明自己用的是哪种策略（敲除或精确敲入）。

这张图要回答的问题（第 1 章句式）：

> 看完这张图，读者应该能够理解 **guide RNA 引导 Cas9 识别紧邻 PAM 的靶序列并在该处产生双链断裂，随后 NHEJ 与 HDR 两种修复途径分别产生不精确的小片段插入/缺失或按供体模板的精确编辑**，并能从图中找到 **事件的先后顺序、PAM 与切点的相对位置，以及两种结果在 DNA 序列层面的差别**。

### 3.2 原始材料与来源

- 材料类型：文字关系（不是数据、不是实验图像）。
- 依据：Jinek 等 2012（Cas9 为双 RNA 引导的 DNA 内切酶，HNH 与 RuvC 样结构域各切一条链）、Doudna 与 Charpentier 2014、Hsu 等 2014（工程化应用与 NHEJ/HDR 结果）、Ran 等 2013（实验方案、PAM 与切点位置）、Chang 等 2017（NHEJ 与替代修复途径）。DOI 见 §7。
- 许可：只引用事实性知识，不复制任何文献中的图；所有图从零生成。
- 作者需要准备的东西：关系表（§3.3）、任务书（§3.4）、三张手绘或模拟草图（§3.5）。书中草图由图像模型模拟铅笔草图，provenance 中如实说明；鼓励读者用自己的手绘替换。

### 3.3 关系表（作者在动笔前确认）

"确立"= 主流教科书与上述综述的共识表述；"简化"= 关系确立但为可读性省略了细节，须在图注中声明。

| # | 起点 | 终点 / 结果 | 关系 | 证据状态 | 简化说明 |
|---|---|---|---|---|---|
| C1 | sgRNA（crRNA:tracrRNA 融合的单链引导 RNA） | Cas9 | 结合，形成 Cas9–sgRNA 复合物 | 确立 | 不画 sgRNA 二级结构细节，只画为带一段"间隔序列"的 RNA 链与发夹支架 |
| C2 | Cas9–sgRNA | 基因组 DNA 上的 PAM（SpCas9 为 5′-NGG-3′） | 识别 PAM | 确立 | 不画 Cas9 沿 DNA 搜索的过程 |
| C3 | sgRNA 间隔序列（约 20 nt） | 靶链（与间隔序列互补的那条 DNA 链） | 碱基配对，形成 R 环；非靶链被置换 | 确立 | 不画 R 环的分步形成 |
| C4 | PAM 的位置 | 非靶链上、紧邻原间隔序列的 3′ 端 | 空间关系 | 确立 | 细节放入插图（图 3-7） |
| C5 | Cas9（HNH 与 RuvC 样结构域） | 两条链在 PAM 上游约 3 bp 处被切开 | 产生双链断裂（多为平末端） | 确立 | 总览图不区分两个结构域，插图中区分 |
| C6 | 双链断裂 | NHEJ（非同源末端连接） | 修复途径之一，不需要模板 | 确立 | 不画 Ku70/80、DNA-PKcs、连接酶 IV 等因子；不画 MMEJ 等替代途径 |
| C7 | NHEJ | 断裂处可能出现小片段插入或缺失（indel） | 结果；位于编码区时可能导致移码、基因功能破坏 | 确立 | 用"可能"表述；NHEJ 也可能准确连接，这种情况下 Cas9 可再次切割，图中不画这一循环 |
| C8 | 双链断裂 + 外源供体模板（带同源臂） | HDR（同源定向修复） | 修复途径之一，需要模板 | 确立 | 不画末端切除、链入侵等中间步骤 |
| C9 | HDR | 按供体模板写入的精确改变（插入或替换） | 结果；在多数细胞中频率低于 NHEJ，主要发生在 S/G2 期 | 确立 | 不给任何效率数值；"频率较低"只在图注中写 |

**明确不画（图注中声明省略）：** 细胞、细胞核、染色体与递送方式（质粒、RNP、病毒）；Cas9 的三维结构；脱靶切割；碱基编辑、先导编辑、Cas12a 等其他系统；NHEJ 与 HDR 的分子因子；任何效率或频率数字。

### 3.4 绘图任务书（全文）

在 SciDraw AI 科研绘图向导（`/zh/figure-workflow`）选择"机制图与流程图"路线，把默认任务书替换为下面内容并下载副本。三张候选图共用这份任务书，只换草图。

```
【用途与读者】开题报告与综述引言的 Figure 1 总览示意图，双栏通栏宽 174 mm、
高约 110 mm；读者为了解分子生物学基础、但未必做过基因编辑的同行与评审。

【目标】让读者按顺序看清：sgRNA 与 Cas9 结合 → 复合物识别 DNA 上的 PAM、
间隔序列与靶链配对 → 在 PAM 上游切开两条链形成双链断裂 → 两种修复途径
（NHEJ：不需模板，可能留下小片段插入/缺失；HDR：需供体模板，得到精确编辑）。
主要信息是"同一个断裂，两种修复，两种结果"。

【材料】教科书与综述层面的已确立关系（Jinek 2012；Doudna & Charpentier 2014；
Hsu, Lander & Zhang 2014；Ran 等 2013）。不含作者数据。

【对象】Cas9（一个圆润的双叶蛋白轮廓）；sgRNA（一条 RNA 链，含间隔段与发夹支架）；
基因组 DNA（双链，用两条平行线及横档表示）；PAM（DNA 上一小段高亮）；
双链断裂（DNA 上的缺口）；供体模板（一段短双链 DNA，两端为同源臂，中间为
待写入的片段）；修复后的 DNA 两条（NHEJ 结果、HDR 结果）。
每个对象只出现一次，DNA 在每个步骤中各出现一段。

【关系】按关系表 C1–C9。步骤之间用同一种实线箭头；断裂处分叉为两条并列箭头，
分别通往 NHEJ 与 HDR；供体模板只出现在 HDR 通道中，并与断裂位置对齐。

【布局】按所附草图的结构；三种候选图分别对应草图 A（线性）、B（中心辐射）、
C（两分支）。底部 10% 留空。

【视觉】白底、扁平二维、细深灰描边，无渐变、阴影、3D。颜色角色：Cas9 蓝灰；
sgRNA 橙；DNA 深灰；PAM 黄；供体模板与 HDR 写入片段青绿；NHEJ 的 indel 位置用
小红紫标记。全图不超过 4 个色相加灰色。对象之间留出标签空间。

【限制】底图中不出现任何文字、字母、数字或符号；不画细胞、细胞核、染色体、
病毒、剪刀、闪电、发光效果；不画 Cas9 的写实三维结构；不画数据或图表。

【图例】在 LaTeX 中制作：实线箭头=步骤；分叉箭头=两种可选修复途径；
黄色=PAM；红紫标记=indel；青绿=供体模板来源的序列。

【验收】C1–C9 逐条可找到；PAM 在断裂的同一侧且紧邻；供体模板只在 HDR 通道；
两条结果通道的 DNA 长度、位置一致以便对照；阅读顺序可用 1–5 编号无歧义标出；
底图无文字；174 mm 宽下叠加 7 pt 标签后可读。
```

### 3.5 三张草图（V0-A / V0-B / V0-C）

草图只承担布局：分区、相对大小、方向、留白。书中由图像模型模拟铅笔草图（provenance 注明"模拟草图"）；提示词见 FIG ch03-02。作者检查每张草图：

- [ ] 是否一眼能看出入口？
- [ ] 分叉点是否清楚，两条结果是否画成并列？
- [ ] 留白是否足够放标签？
- [ ] 无文字（允许作者事后在 LaTeX 中叠加编号圈）。

### 3.6 候选图（V1-A / V1-B / V1-C）

操作：SciDraw AI `/ai-drawing` → 草图模式 → 上传草图 → 粘贴 §3.4 任务书英文版提示词（见 FIG ch03-03）。三次只换草图。书中由 Codex 图像生成完成同一步骤（把草图作为参考图输入）；若参考图输入不可用，改用 FIG ch03-03 中写明的文字布局描述，并在 provenance 中记录。

预期问题（正文用于讲解，生成结果不一定全部出现，以实际为准记录）：

- A：步骤清楚，但 NHEJ/HDR 被挤在右端上下叠放，结果对比区太小；读者在分叉处可能先看下方。
- B：没有入口，视线在中心与四周之间来回；"sgRNA""PAM""HDR 结果"成为同级卫星，层级被拉平；箭头有进有出，方向难辨。
- C：结构符合任务，但常见细节错误：PAM 被画在断裂的另一侧或离得很远；供体模板漂在两条通道之间；两条通道 DNA 基线高度不同；可能自行加入细胞核轮廓。

### 3.7 比较与选择

比较表（图 3-4 的内容，正文也以表格呈现）：

| 标准 | A 线性 | B 中心辐射 | C 两分支 |
|---|---|---|---|
| 入口是否唯一明确 | 是（左） | 否 | 是（左上） |
| 阅读方向与事件先后一致 | 是 | 部分（需靠箭头） | 是 |
| 两种结果能否在同一基线上直接对照 | 否（上下挤在右端） | 否（分在两侧） | 是（并列通道） |
| 主要信息（同一断裂、两种结果）的视觉权重 | 低（占约 1/4 宽） | 中 | 高（占下半幅） |
| 174 mm 宽下的标签空间 | 紧 | 中 | 足 |
| 适合的用途 | 幻灯片逐步展示 | 概念关系图（非时序） | 论文总览图 |

**选择：C。** 理由写进修改记录："本图的主要信息是两种修复结果的对比，C 把它放在最大的区域并让两条通道对齐，读者能在同一位置比较 indel 与精确写入；A 保留为汇报幻灯片的逐步动画版本。"

### 3.8 修订（V2 → V3）

以 V1-C 为起点，用参考图修改逐条处理，每次一个目标。修改指令全文：

**修改 1（PAM 位置）**

```
Edit the selected image. Change only one thing: move the small yellow PAM
segment so that it sits directly next to the right side of the DNA gap at the
cleavage step, on the upper strand, touching the gap. Keep every other object,
color, line weight and position unchanged. Do not add any text.
```

检查：PAM 与断裂相邻、在同一侧；其余对象位置不变（与 V1-C 叠图对比）。

**修改 2（供体模板只在 HDR 通道并与断裂对齐）**

```
Edit the selected image. Change only one thing: move the short teal donor DNA
so that it lies inside the lower repair lane only, directly above the DNA gap
in that lane, horizontally centered on the gap. Remove any copy of the donor
outside the lower lane. Keep everything else unchanged. No text.
```

检查：供体只出现一次，位于 HDR 通道，居中于缺口。

**修改 3（两条通道对齐）**

```
Edit the selected image. Change only one thing: make the two repair lanes the
same height, and draw the DNA in both lanes at the same horizontal position and
the same length, so the two results line up vertically for comparison. Keep
colors, objects and the top row unchanged. No text.
```

检查：两条结果 DNA 左右端点对齐（在 PNG 上量像素，误差 < 2%）。

**修改 4（删除多余对象）** —— 若出现细胞核或其他未列对象：

```
Edit the selected image. Remove the cell nucleus outline and any background
shapes. Change nothing else. No text.
```

### 6.2 练习

**练习 1（纸笔）：给一张图找入口。** 从你所在领域近期的一篇论文中选一张总览图或图形摘要。（a）不看图注，用 5 秒看图，写下你看到的第一、第二、第三个元素；（b）再请一位同学独立做同样的事；（c）比较两人的顺序，指出是哪些手段（尺寸、对比、位置、箭头、编号）造成了一致或分歧；（d）在复印件上画出你认为更好的视线路径，并说明需要移动哪两个元素。

**练习 2（SciDraw AI 实操）：一份任务书，三张草图。** 选择一个包含"分叉"或"对比"的过程（例如：一种材料的两种失效模式，一项算法的两种分支处理）。（a）写出关系表和任务书；（b）手绘线性、中心辐射、分支对比三张草图并拍照；（c）在 SciDraw AI 草图模式中，用同一份任务书文字分别上传三张草图生成候选图；（d）对照草图记录每张的偏离，请一位同学给三张图编阅读顺序；（e）用本章的比较表打分并写出选择理由。提交：三张草图、三张候选图、偏离记录、比较表。
